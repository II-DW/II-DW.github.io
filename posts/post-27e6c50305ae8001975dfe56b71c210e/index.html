#개념

SIFT란?

Scale Invariant Feature Transform

말 그대로, 크기, 회전, 조명 등이 변하더라도 이미지에서 특징을 추출해낼 수 있도록 하는 기술이다.

SIFT의 실행순서

1. Scale-Space Extrema Detection (스케일 공간 극값 탐지)

📌 무엇을?

입력 이미지의 크기가 다양할 때, 여러가지 크기에서 특징점 후보(keypoint)를 찾는 단계

📌 왜?

앞서 말했듯이, 이미지의 크기가 변하더라도 특징을 추출해낼 수 있도록 하기 위해서

📌 어떻게?

가우시안 블러 G(σ)G(\sigma)G(σ)를 여러 σ\sigmaσ로 적용한 피라미드(옥타브/스케일 생성)

LoG를 DoG로 근사해 사용:

D(x,y,σ)=((G(x,y,σ)−G(x,y,σ))∗I(x,y)D(x, y, \sigma) = ((G(x, y, \sigma) - G(x, y, \sigma)) * I (x,y)D(x,y,σ)=((G(x,y,σ)−G(x,y,σ))∗I(x,y)

각 위치/스케일에서 3x3x3 이웃 (공간 8 + 위/아래 스케일 포함 26개)과 비교해 로컬 최대/최소(극값)면 후보로 채택

보통 한 옥타브마다 해상도를 1/2로 다운샘플, 스케일 간격 k는 예: 21s2^{\frac{1}{s}}2s1​등

2. Keypoint Localization (정밀 위치 추정 및 불량 후보 제거)

📌 무엇을?

후보의 정확한 위치/스케일을 소수점 수준으로 보정하고, 잡음/엣지 유사점 제거

📌 왜?

대비가 너무 약하거나(노이즈), 단순 엣지 위의 점은 매칭에 불안정

📌 어떻게?

DoG를 테일러 전개로 근사해 서브픽셀 보정 (정밀 좌표/스케일)

저대비 제거: ∣D(x^)∣|D(\hat{x})|∣D(x^)∣가 임계값(예: 0.03) 미만이면 버림

엣지 응답 제거: Hessian H=[DxxDxyDxyDyy]H = \begin{bmatrix} D_{xx} & D_{xy}\\ D_{xy} & D{yy} \end{bmatrix}H=[Dxx​Dxy​​Dxy​Dyy​]의 고유값 비로 판별

edge ratio R=(TrH)2detHedge ~ ratio ~ R = \frac{(TrH)^2}{det H}edge ratio R=detH(TrH)2​가 임계(r=10 등)보다 크면 제거 —> 엣지 방향으로만 강한 점 배제

3. Orientation Assignment (주방향 부여)

📌 무엇을?

각 키포인트에 주된 방향 (orientation)을 붙임.

📌 왜?

패치를 이 방향으로 정렬하면 회전 불변성 확보

📌 어떻게?

키포인트 스케일에 비례한 이웃에서 그래디언트 (m,θ)(m, \theta)(m,θ) 계산 후, 가우시안 가중으로 완만히 집계

36빈(10도 간격) 방향 히스토그램의 피크를 주방향으로 채택

피크의 80% 이상인 보조 피크가 있으면 복수 방향 키포인트를 추가 생성 (매칭 강건성 up)

4. Keypoint Descriptor

📌 무엇을?

회전 정렬된 주변 패치를 숫자 벡터 (보통 128 차원)로 요약

📌 왜?

서로 다른 이미지에서는 같은 점을 수치적으로 비교하려면 고정 길이 특징이 필요.

📌 어떻게?

정렬된 패치를 4x4셀로 나눔. (총 16셀)

각 셀마다 8방향 히스토그램 (그라디언트 크기 가중, 가우시안 윈도) —> 16 x 8 = 128D

삼선형 보간 (공간/방향으로 분산 가중)으로 양자화
